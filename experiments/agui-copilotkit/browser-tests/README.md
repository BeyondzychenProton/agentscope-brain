# 浏览器流式验证

此测试使用浏览器经过实际验证页面、Runtime 和 Java 服务，在模型 HTTP 边界提供可控响应。它不验证真实模型的兼容性。

1. 在此目录运行 `npm ci`，并运行 `npx playwright install chromium` 安装浏览器。
2. 将独立 Java 服务的模型地址配置为 `http://127.0.0.1:11435/v1`、模型名 `fixture-model`，API key 任意；再启动 Java 服务与验证页面。测试期间不要启动其他占用 11435 端口的服务。
3. 运行 `npm test`。页面默认地址是 `http://127.0.0.1:3000`；可用 `DEMO_URL` 覆盖。可选地通过 `CHROMIUM_EXECUTABLE` 指定已有 Chromium 浏览器的完整路径。

测试自身启动模型替身。替身逐次发送两段文本，只有浏览器显示前一段后才发送下一段，并在两段都可见后发送结束事件。失败时检查浏览器测试输出；测试不使用真实凭据。
