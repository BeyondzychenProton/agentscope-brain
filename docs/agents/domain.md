# Domain Docs

本仓库采用 single-context 布局。

## 探索前读取

- 仓库根目录 GLOSSARY.md：统一领域术语。
- 仓库根目录 docs/adr/：按当前工作主题读取相关 ADR。

上述文档或目录不存在时，静默继续。
本次配置仅引用已有 GLOSSARY.md，不创建 ADR、不改写领域或设计文档。

## 文档布局

- GLOSSARY.md：整个仓库共享的领域术语。
- docs/adr/：仓库级架构决策记录，按实际需要维护。

## 使用领域术语

Issue 标题、设计讨论、重构建议和测试名称中的领域概念，
沿用 GLOSSARY.md 的定义及命名，避开其中明确排除的同义词。

遇到缺失概念时，先判断是否确有领域术语缺口；
需要补充时记录为后续 domain-modeling 事项。

## 显式说明决策冲突

若建议与已有 ADR 冲突，明确指出对应 ADR 和重新讨论的理由，
交由用户确认。
