## 1. 入口与体验顺序

[统一原型文件](../../prototypes/正式Web工作台总览-prototype.html)可双击打开；已运行回环服务时，访问[本机评审入口](http://127.0.0.1:8931/正式Web工作台总览-prototype.html?scene=progress)。回环服务命令：

```powershell
python -m http.server 8931 --bind 127.0.0.1 --directory 'D:\code project\agentscope\prototypes'
```

场景选择会重置当前合成场景及其草稿。普通侧栏切换保留其他会话；不要把场景重置当作真实会话切换。

| 场景 | 体验路径 | 应看到的行为 |
| --- | --- | --- |
| 完整预约 `scene=progress` | 下一条执行说明 ×3 → 选择人员／时长 → 提交 → 确认预约 | 聊天内阶段到达；表单在底部；接纳回答后另出固定提案，确认后才显示合成回执 |
| 长表单 `scene=long` | 先空提交，再填写参会人、示例字段 1／30，保存及提交 | 全部 32 字段包含人员／时长和 30 示例字段、共 8 组；错误保留输入，首错可定位，内部滚动及固定动作区 |
| 图片与发送恢复 `scene=images` | 输入文字 → 更多演示操作添加示例图片／模拟就绪 → 选择下次发送结果不明 → 点击发送 → 刷新 → 模拟回查原提交 | 未就绪不能发送；未知结果冻结待发内容；已接纳只显示一次正式模拟消息并清理对应草稿 |
| 操作结果待核对 `scene=unknown` | 查看消息及过程 | 当前任务仍占用，没有再次预约按钮；与普通消息接纳未知是两个场景 |
| 内容渲染 `scene=render` | 查看列表／表格／代码／链接／未知占位 | 固定安全 HTML 的视觉示例；不是 Markdown 库或净化器的实际集成 |

其他入口：

- 表单阶段“更多演示操作 → 模拟草稿冲突”，比较两份可读字段后选择；重新应用只保存草稿。
- 确认阶段可模拟到期；旧任务未核实结束前不可写，明确模拟安全结束后恢复输入，不自动续期。
- 会话更多菜单仅提供改名；侧栏按普通模拟会话列表标题搜索。正式全范围搜索仍需服务端接口。
- “登录流程”仅模拟登录 → 受限改密 → 工作台，所有口令字段只读，不接收真实凭据。“退出演示”只清理本原型当前标签的专用记录。

## 2. 已执行的浏览器检查

在当前应用内浏览器人工驱动 DOM／按钮并读取可见结果；不是独立 Chrome／Edge 双浏览器验收，也没有编写原型测试套件。

| 检查 | 观察结果 |
| --- | --- |
| 阶段 → FORM → 独立确认 → 合成成功回执 | 按顺序出现；提交补充信息不直接显示预约成功 |
| 空表单校验与首错 | 提示缺人员；焦点定位候选按钮，填写保留 |
| 长表单 | 实际 30 个示例 input + 人员／时长，共 32 逻辑字段、8 分组；首尾必填值保存后不丢 |
| 普通短表单 | 1280×720 下人员与时长全部选项位于字段可视区域内，底部区域仍不超过聊天可用高度的一半 |
| 断线 | 提交禁用，首尾填写保留；恢复后可统一提交 |
| 草稿冲突 | 两份人员／时长可读比较，选择重新应用后仍须点击提交 |
| 确认过期 | 禁止旧确认，显示等待安全结束；模拟安全结束后恢复普通输入 |
| 版本查看（调整前，现已移出） | V1 主区只读，返回后原普通文字仍保留；发现滚动恢复变量引用错误并修复，复查无新增错误 |
| 会话归档（调整前，现已移出） | 当时检查归档不改变任务状态；当前原型已移除全部归档入口及动作 |
| 图片合成状态 | 示例图片未就绪时发送禁用；就绪后仍等用户点击；结果未知时禁止重复发送／修改原内容 |
| 刷新与原提交回查 | 待核对内容及模拟引用恢复；核对为已接纳仅一条用户消息；修复同一 composer 未及时清理已接纳文字的问题 |
| 文字与新会话 | 当前标签刷新恢复文字；空白意图不在正式模拟列表出现，首条发送接纳后出现标题 |
| 键盘 | Shift+Enter 换行不发送，Enter 发送；原型含 composition 防护，但未做真实中文输入法操作验证 |
| 普通文字粘贴 | 发现变量引用错误并修复；重新粘贴及历史返回后日志无新增错误 |
| 登录流程 | 合成登录 → 受限改密 → 工作台的页面转换可用，不执行真实认证或改密 |

新版本修正后再次完成内联脚本语法检查；历史错误日志保留，不能声称整个开发过程从未出现错误。

## 4. 尚未证明的事项

原型没有 Vue／Element Plus／Ajv／markdown-it／DOMPurify 依赖，也未接后端、对象存储、模型、AgentScope 或会议系统。模拟持久快照保存在当前标签专用 sessionStorage，仅承载演示状态／文字及引用元数据，不保存原图、base64 或 blob URL；不证明真实鉴权、上传票据、FORM 服务端草稿或事务幂等。

文件选择／粘贴／拖入图片入口已布线，但本次以合成图片检查状态门槛和刷新；未做真实文件上传、有效能力限制或重选后的服务端绑定验证。真实 IME、多标签退出通知、存储禁用／配额故障、长正文压力、上翻阅读与输入中阶段到达的完整焦点矩阵仍是正式实施验证项，不能从原型代码存在推断通过。

#22 负责真实接口与持久化接缝；#23 负责实施切片、目标浏览器矩阵及真实闭环。当前整体评审不会触发 Git 提交／推送、部署或真实会议写入。
