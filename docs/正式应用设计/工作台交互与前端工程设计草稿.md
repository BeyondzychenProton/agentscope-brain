## 4. 参照与正式契约的必要对齐

以下来自既定范围，不作为本轮待选择的新设计：

- 不带入角色切换、管理员登录、管理页面及管理 API；一期仍为一个会议室数字员工。
- 切换或关闭页面只影响展示订阅，不取消 Run；参照的本地 abort 行为不能直接复用。
- 将预设“思考过程”对齐为可信阶段、工具动作和结果摘要，不展示原始推理。
- FORM 与操作确认分别消费已确认契约；表单提交不是预约／取消授权，历史卡片不能重新执行。
- 上传入口按一期图文能力设计，不从参照占位按钮推导语音、通用文件或云盘接入已纳入一期。
- 原型演示的会话分享、共享工作区和多个管理入口不自动成为正式需求；有新场景时先核对 #14 范围。
- 连接恢复与任务恢复分开；网络重连不自动执行模型、续接 pending 或重试外部写操作。

## 5. 工程轮的补充事实输入

以下保留选型时的事实输入；当前用户已确认 Element Plus 和有限 form-v1 renderer + Ajv，JSON Forms Vue 仍为研究过的备选，不是已采用依赖：

- [Vue 官方 TypeScript 说明](https://vuejs.org/guide/typescript/overview.html)支持 Vue 3、TypeScript 与 Vite 的组合；Vite 转译不等于类型检查，需独立运行 vue-tsc。
- 固定 [JSON Forms v3.8.0 Vue README](https://github.com/eclipsesource/jsonforms/blob/v3.8.0/packages/vue/README.md)及[包依赖](https://github.com/eclipsesource/jsonforms/blob/v3.8.0/packages/vue/package.json)表明，可注册自定义 renderer、传入自定义 Ajv、监听数据及错误变化，支持 readonly；对应 Vue peer 为 ^3.5.0、Core 为 3.8.0。该版本是核验锚点，不代表项目已选用或它是当前最新版本。
- [JSON Forms Vue 集成页](https://jsonforms.io/docs/integrations/vue/)仍标记 preview。复用其绑定／校验与维护本项目有限字段 renderer 是后续需比较的工程取舍；它不提供本平台的交互持久化、草稿 CAS、确认授权或恢复生命周期。
- [固定 validator 源码](https://github.com/eclipsesource/jsonforms/blob/v3.8.0/packages/core/src/util/validator.ts)使用 Ajv 与 ajv-formats；[Ajv 默认方言](https://ajv.js.org/json-schema.html)支持 draft-07。默认校验配置不能代替服务端 form-v1 白名单校验。
- 时间格式要按实际锁版核验：[ajv-formats v2.1.1](https://github.com/ajv-validator/ajv-formats/blob/v2.1.1/README.md)的 time 时区可选、date-time 时区必需；JSON Forms v3.8.0 声明依赖 ^2.1.0。当前官网的 time 时区要求不能直接套回旧依赖。无论选择哪条渲染路径，仍须统一上海业务时间的输入、规范化和前后端校验；不重新决定业务时区。此条纠正初次笔记未区分版本的概括。

完整事实、版本边界和两条 renderer 路线见[前端工程与受控表单渲染补充核验](../调研/正式Web应用/前端工程与受控表单渲染补充核验.md)。以上为官方资料及固定源码核验，未运行候选依赖安装或组件集成；与下节单文件原型的浏览器检查分开记录。

## 11. 工程收口的补充事实输入

[聊天 Markdown 与前端锁版补充核验](../调研/正式Web应用/聊天Markdown与前端锁版补充核验.md)已由事实研究补齐，以下区分官方事实、工程候选和已有契约：
