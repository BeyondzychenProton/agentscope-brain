## 当前边界

- 以用户工作台、内容渲染、可展开执行过程、运行事件投影及人机交互为主线，覆盖支撑真实使用的后端、持久化、恢复和会议 MCP 闭环。
- 一期支持通用动态表单：数字员工可按当前任务提出结构，服务端校验后由前端使用受控组件渲染。表单数据收集不默认替代预约／取消前的具体操作确认。
- 2026-10-24 #22 最新范围：当前任务在数据库预置一个普通账号及所需授权／员工配置，聚焦用户功能；不实现管理员角色、管理端、账号／授权／配置管理流程或维护命令，后续由另一个任务补齐。普通用户真实登录、首次改密及服务端身份／权限校验继续保留。此调整优先于旧规格中的管理员初始化及维护交付要求。
- #22 用户链路已确认：登录固定有效 24 小时且不自动续期；多浏览器可并行登录，普通退出仅结束当前会话；图片使用 MinIO 私有原件，经后端校验上传及鉴权代理读取；启动校验基础预置，不以模型／MCP 在线成功作为整个应用启动前置。
- #22 Q11—Q13 已确认：未发送图片自上传票据创建起暂存 24 小时；普通发送使用独立持久提交控制及原键封闭；随机确认凭据保留摘要并增加加密恢复副本，刷新不改变原十分钟期限或消费状态。最小字段、锁序及 SDK 接缝继续收敛，尚未修改 DDL。
- #22 Q14—Q15 已确认：后端采用 Java 17 + Spring Boot 4.1.2，覆盖旧 Boot 3 输入；AgentScope Java 固定 v2.0.4。其他组件及 Jackson／Reactor／Kotlin 的有效依赖组合仍待求解与验证，旧 Spring 版本研究不直接充当新路线适配证明。
- 2026-10-25 #22 Q16—Q18 已确认：networknt 3.0.6 配合 Boot 管理的 Jackson 3.1.7，平台控制 form-v1 白名单与字段错误；SDK 挂起状态通过专用适配器终结，先隔离验证再启用；时间值固定上海 `+08:00`、秒精度及严格表示，前后端共享 fixture。机制采用不等于已实施或通过运行验收。
- 用户已提供本轮参照原型，见[参照原型接收记录](参照原型接收记录.md)及其原始文件副本。已确认参照视觉、PC 验收、底部表单及共存方式；采用 Vue 3 + TypeScript + Vite + Vue Router + Pinia、Element Plus 和有限 form-v1 renderer + Ajv。执行过程在聊天内折叠，实时更新可信阶段说明；不设右侧详情抽屉；markdown-it + DOMPurify、分层及精确初始依赖已由 Q19—Q21 确认；整体修订版已通过评审，依赖尚未安装。
- 2026-10-24 用户调整：一期前端不开发“我的记忆”页面、入口及查看／编辑／清空交互；已有后端记忆、隔离、学习和恢复设计保留。该调整不自动承诺另行交付记忆管理 API。
- 2026-10-24 整体原型评审调整：一期不开发归档列表及归档／恢复操作，不显示“连接正常”常驻标记；不展示发布／会话版本标签、版本历史或升级相关入口。实际断线等异常仍提示；后台原有归档、固定版本和隔离／恢复规则保留。
- 多渠道适配、绑定、续传和投递逻辑，以及数据保留策略延后；单企业、一个会议室员工、单节点低并发边界继续沿用。
