# 后端核心依赖锁版补充核验

> 日期：2026-10-24，Asia/Shanghai。议题：[后端工程与用户链路 #22](https://github.com/BeyondzychenProton/agentscope-brain/issues/22)。  
> 当前决定：用户已采用 Q14 **Java 17 + Spring Boot 4.1.2**，及独立的 Q15 **AgentScope Java 2.0.4／固定提交**；旧 Boot 3 输入由该决定替代。MyBatis-Plus Boot 4 starter 3.5.17、MinIO SDK 9.0.3 的精确版本仍是候选，见第 7 节。
>
> 证据状态：GitHub 官方发布 API、固定 tag／commit、官方文档及 Maven Central 发布 POM 的静态核验。没有安装依赖、生成正式 pom、执行 Maven 依赖求解／编译或运行集成。本页不宣称完整传递依赖兼容；第 3—5 节保留 Boot 3 当时核对及条件对照，不作为当前推荐。

## 1. 先区分既定路线与新发现的支持边界

最初的 Java 17／Spring Boot 3 输入已在本轮得到更新：用户基于下列支持事实，采用 Java 17／Boot 4.1.2。Maven、Spring MVC、MyBatis-Plus、Spring Security + Spring Session JDBC 及 MinIO 路线继续沿用。

**Boot 3 不能再称为当前仍获 OSS 维护的分支。** Spring 官方 2026-06-25 发布说明明确，**3.5.16 是 3.5.x 最后一个 OSS 版本**；继续获得 OSS 支持需转向 4.0／4.1，或另有商业支持。当前 Boot 3 路线内最高已发布稳定候选为 **3.5.16**，是有条件的保留路线，不能把它描述为仍有后续免费补丁承诺。[官方发布及支持说明](https://spring.io/blog/2026/06/25/spring-boot-3-5-16-available-now/)

Boot 3.5.16 要求 Java 17，官方文档列出的 Framework 基线为 6.2.19；这支持既有 Java 17 入口，不代表第三方库已验证兼容。[官方系统要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)

## 4. 第三方直接声明及真实交点

主要证据只展开到影响当前组合的直接声明，没有遍历所有可选能力：

- [AgentScope core 2.0.4 发布 POM](https://repo.maven.apache.org/maven2/io/agentscope/agentscope-core/2.0.4/agentscope-core-2.0.4.pom)：Reactor Core **3.8.2**，Jackson databind／JSR310／YAML **2.21.1**、annotations **2.21**，OkHttp 与 okhttp-jvm **5.3.2**。其[依赖 BOM](https://repo.maven.apache.org/maven2/io/agentscope/agentscope-dependencies-bom/2.0.4/agentscope-dependencies-bom-2.0.4.pom)采用 Reactor BOM **2025.0.2**，与 Boot 3.5.16 的 Reactor 系列不同。
- [MyBatis-Plus Boot 3 starter 3.5.17 发布 POM](https://repo.maven.apache.org/maven2/com/baomidou/mybatis-plus-spring-boot3-starter/3.5.17/mybatis-plus-spring-boot3-starter-3.5.17.pom)：直接带 MyBatis-Spring **3.0.5**，其自身依赖管理导入 Boot **3.5.9**；[mybatis-plus 3.5.17 POM](https://repo.maven.apache.org/maven2/com/baomidou/mybatis-plus/3.5.17/mybatis-plus-3.5.17.pom)声明 MyBatis **3.5.19**。通用包还列有 optional MyBatis-Spring 2.1.2，不能因此把 Boot 3 starter 的 3.0.5 改回 2.x；optional 脚本引擎／Cloud 项也不自动加入本任务。
- [MinIO 9.0.3 发布 POM](https://repo.maven.apache.org/maven2/io/minio/minio/9.0.3/minio-9.0.3.pom)：OkHttp **5.3.2**，Jackson core／databind **2.21.2**、annotations **2.21**。它没有要求把应用换成特定 Spring Boot 主版本，但同一应用仍须统一共享类库。
- [OkHttp JVM 5.3.2 发布 POM](https://repo.maven.apache.org/maven2/com/squareup/okhttp3/okhttp-jvm/5.3.2/okhttp-jvm-5.3.2.pom)：Okio JVM **3.16.4**、Kotlin stdlib **2.2.21**。因此“业务代码只写 Java”不能消除 Kotlin 运行时交点。

| 交点 | 判断及尚不能作出的结论 |
| --- | --- |
| OkHttp | AgentScope 与 MinIO 直接声明均为 5.3.2，有一致的候选依据；Boot BOM 未替它管理版本。仍未证明所有调用 API 及 HTTP 行为。 |
| Jackson | 三方均在 2.21 系列，优先由 Boot Jackson BOM 统一到 2.21.4／annotations 2.21 是候选；这是补丁统一推论，不是已通过的序列化／模型适配验收。 |
| Reactor | Boot 管理 3.7.19，SDK 直接声明 3.8.2，是需要解决的跨系列差异。直接按 Boot 管理降级 SDK，或反向导入 SDK dependencies BOM 覆盖整个 Boot 平台，都缺少本次静态材料足以确认的兼容证明。 |
| Kotlin | Boot 管理 1.9.25，OkHttp JVM 声明 2.2.21。不能因为顶层 OkHttp 相同就遗漏这个差异；须核对有效图及 API 使用后明确是否定点覆盖，不在本页擅自选择。 |
| MyBatis-Spring／Boot | Starter 自身引用 Boot 3.5.9 不等于应用必须退回该补丁，也不证明搭配 3.5.16 已通过。以应用 Boot BOM 为主，后续检查自动配置和实际 Mapper／事务行为。 |

## 5. 旧 Boot 3 条件分支，历史对照

**本节只保留用户当时若坚持旧 Boot 3 路线的条件对照；用户现已采用 Boot 4.1.2，不再将本节作为当前推荐或待确认项。** 当时条件候选为：**Java 17 + Boot 3.5.16 + AgentScope 2.0.4／固定提交 + MyBatis-Plus Boot 3 starter 3.5.17 + MinIO SDK 9.0.3**。Spring Framework／Security／Session、Jackson、MySQL 驱动以该 Boot BOM 为依据，第三方顶层组件显式锁定，不单独追全家最新。

这是一组**待求解、待验证**的候选：Reactor 与 Kotlin 的最终解析版本仍需处理，不能先宣布“BOM 优先即可兼容”。AgentScope 可将自身组件统一到 2.0.4，但不应把管理其所有外部依赖的 `agentscope-dependencies-bom` 无审查地作为全应用覆盖来源；需要用到的 SDK 具体模块仍由接入切片列明。

后续顺序：先确认 Boot 支持范围与顶层候选，再在明确授权的实施切片生成有效 POM／依赖树，逐项解释 Reactor／Kotlin 等版本选择；核对字节码与编译后，验证 MVC／SSE、Security／Session、Mapper／事务、SDK 状态及 MinIO 流式往返。Maven 工具路线已定，Wrapper 精确版另行锁定；本次没有运行上述构建或集成，也没有用静态 POM 代替验收。

## 6. 已采用 Boot 4.1.2 的最小官方依据与兼容边界

基于第 1 节的新支持事实，用户已采用 **Q14 Java 17 + Spring Boot 4.1.2**，替代旧 Boot 3 输入；并独立采用 **Q15 正式固定 AgentScope 2.0.4／上述 commit**。采纳顶层版本不等于完整 Boot 4 依赖图已求解或集成验收通过。

官方系统要求明确：Boot **4.1.2 仍支持 Java 17**，Framework 基线为 **7.0.10**，Servlet 基线提升为 6.1。升级 Boot 路线不强迫本项目同时升级 Java 主版本，但旧 6.2／Security 6.5／Session 3.5 的研究只能作为业务接缝背景，不能充当新依赖的精确适配证明。[Boot 4.1 官方系统要求](https://docs.spring.io/spring-boot/4.1/system-requirements.html)

本次读取 [Boot 4.1.2 发布 BOM](https://repo.maven.apache.org/maven2/org/springframework/boot/spring-boot-dependencies/4.1.2/spring-boot-dependencies-4.1.2.pom)，其直接管理属性为：

| 管理项 | Boot 4.1.2 声明 |
| --- | --- |
| Framework／Security／Session | 7.0.10／7.1.2／4.1.1 |
| Jackson 3 BOM | `tools.jackson:jackson-bom:3.1.7` |
| Jackson 2 兼容依赖 BOM | `com.fasterxml.jackson:jackson-bom:2.21.7`；annotations 仍为 2.21 |
| Reactor BOM | 2025.0.8，对应 reactor-core **3.8.8**；与 AgentScope 的 3.8.2 同一 minor 系列，但不是同一精确版本。 |
| Kotlin BOM | 2.3.21；与 OkHttp JVM 声明的 stdlib 2.2.21 仍须核对实际解析，不能将较新数值当作兼容证明。 |

展开坐标亦由官方 [Boot 4.1.2 管理依赖表](https://docs.spring.io/spring-boot/appendix/dependency-versions/coordinates.html)交叉核对。

官方 [MP Boot 4 starter 3.5.17 发布 POM](https://repo.maven.apache.org/maven2/com/baomidou/mybatis-plus-spring-boot4-starter/3.5.17/mybatis-plus-spring-boot4-starter-3.5.17.pom)确实存在，坐标为 `com.baomidou:mybatis-plus-spring-boot4-starter:3.5.17`，直接 MyBatis-Spring **4.0.0**，其自身依赖管理导入 Boot **4.0.1**。这支持存在 Boot 4 专用接入路线，不等于已验收本项目搭配 4.1.2；不能同时混用 Boot 3／4 两个 starter。

AgentScope core 2.0.4 的上述发布 POM **没有直接的 org.springframework 依赖**，所以 SDK core 不能仅因版本号 2.x 就被认定硬绑定 Boot 3；这一结论限 core 直接声明，不扩展成所有 SDK 扩展／starter 均无 Spring 约束。

Boot 官方迁移指南说明，默认优先使用 Jackson 3，核心 groupId／包名从 `com.fasterxml.jackson` 转到 `tools.jackson`，annotations 是继续共享旧坐标／包名的例外。Boot 也提供已弃用的 Jackson 2 兼容模块；这不是要求本项目启用该模块。[官方 Jackson 迁移说明](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.0-Migration-Guide#upgrading-jackson)

因此，Boot Web 使用 Jackson 3、AgentScope／MinIO 内部继续使用 Jackson 2 **具有坐标与包名层面的并存候选依据**，但不证明 ObjectMapper、MessageConverter、注解、SDK 数据类型或 MyBatis JSON TypeHandler 会自动正确桥接。基于已采用的 Q14，后续以 Boot 4 BOM 为主核验两套 Jackson、Reactor、Kotlin 与各自动配置；本次不擅自覆盖、不安装、不构建，也不将整个组合宣布可用。
