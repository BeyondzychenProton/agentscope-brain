## 1. 范围与术语

本次只支持普通聊天输入框的文字草稿及待选图片取舍；已定技术栈和实时阶段说明不在研究范围内。

“业务 Session”是平台会话；“页面会话／标签页”是浏览器存储边界，两者不能混称。FORM 的服务端草稿、CAS、修订和恢复继续沿用[既定交互规格](../../正式应用设计/动态表单与交互请求生命周期设计规格.md)，不改为本地草稿。

## 2. sessionStorage 的官方事实

| 场景 | 核验结论及来源 |
| --- | --- |
| 同标签页刷新 | 页面会话可跨刷新和恢复保留 sessionStorage，因此可承载已成功写入的普通文字。[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage) |
| 隔离维度 | 按 origin 与顶层标签页分区；浏览器不会再按应用 userId 或业务 sessionId 自动分区。[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage) |
| opener 克隆 | 有 opener 的新页面可能获得其初始副本；之后双方修改独立，不持续同步。去掉 opener 可避免该复制路径。[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)、[WHATWG getter／复制规则](https://html.spec.whatwg.org/multipage/webstorage.html#the-sessionstorage-attribute) |
| 关闭标签页 | 页面会话的通常生命周期到标签／窗口关闭为止；浏览器也有页面会话恢复行为，产品不能把“关闭后一定可恢复”或“关闭就是退出清理”当承诺。[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)；后半句为生命周期的应用判断。 |
| 访问／写入异常 | 获取 storage 可能抛 SecurityError；setItem 无法保存时可能抛 QuotaExceededError，例如策略限制或配额耗尽。[WHATWG Storage API](https://html.spec.whatwg.org/multipage/webstorage.html#the-storage-interface)、[sessionStorage getter](https://html.spec.whatwg.org/multipage/webstorage.html#the-sessionstorage-attribute) |
| 值与删除范围 | Storage 接收字符串键值；removeItem 删除指定键，clear 清空当前存储区全部键值。[WHATWG Storage API](https://html.spec.whatwg.org/multipage/webstorage.html#the-storage-interface) |
| 其他标签同步 | sessionStorage 的 storage 事件只到同一顶层上下文中的同源其他文档，不广播到独立标签。[MDN storage event](https://developer.mozilla.org/en-US/docs/Web/API/Window/storage_event) |

上述是存储 API 能力，不是所有设备和浏览器策略下的持久性保证；无需为本研究假定固定容量或依赖浏览器退出时的脚本执行。

## 3. 普通文字草稿的项目建议

以下是结合官方边界提出的应用规则，**不是浏览器原生按用户隔离的能力，也不是已确认决定**。

1. 建议采用应用前缀与版本，加可信 `userId × businessSessionId` 组成键，例如 `agentscope-brain:chat-draft:v1:<userId>:<sessionId>`；实际编码应避免标识拼接歧义。userId 来自已核验登录态，不能以路由或草稿自报身份决定归属。
2. 只恢复当前登录用户仍可访问会话的文字，回填输入框后等待用户动作；恢复草稿不自动发消息、继续 Run 或触发任何工具。当前 Session 等待 FORM 时，仍按既定规则限制普通文字发送。
3. 同标签内切换业务 Session 使用各自键；独立标签各自保存，因此允许同一业务 Session 出现不同本地草稿，不宣称自动同步。opener 副本也必须重新核验身份和会话后才展示。
4. 显式退出、登录失效或检测到身份切换时，先停止展示，再按应用前缀清理当前标签的相关草稿；不用 clear 误删同源其他应用数据。应用前缀是维护边界，不是安全隔离机制。
5. 当前标签清理不会删除其他标签的独立副本；其他标签应在获知退出／失效及重新核验身份时分别清理和阻止旧内容展示。不能靠 sessionStorage 的 storage 事件声称已完成跨标签退出通知。
6. 读写及解析失败时保留当前页面可用输入，明确提示本标签刷新恢复不可用；不能显示虚假的“已保存”。不把口令、token 或确认凭据放进草稿。
7. 草稿删除与消息接纳分开：可在服务端确认接纳后清理对应文字；发送结果未知时保留输入并按既定接纳查询处理，恢复文字不产生新的自动发送。

无需在本轮引入跨设备草稿、服务端普通文字草稿或 localStorage 长期保存；这些是不同产品范围，不能从 sessionStorage 可用性推出。

## 4. 本地图片、预览与已上传素材的区别

| 对象 | 官方事实／项目含义 |
| --- | --- |
| 本地 File／FileList | 文件选择器返回用户选择的文件对象。[MDN 文件使用说明](https://developer.mozilla.org/en-US/docs/Web/API/File_API/Using_files_from_web_applications)；只留在页面内存的引用不形成应用的刷新恢复机制。后半句为工程判断。 |
| 文件名／路径字符串 | 文件 input 的 value 不能设为非空文件路径，否则抛 InvalidStateError；显示名不能重新取得文件内容。[WHATWG input value](https://html.spec.whatwg.org/multipage/input.html#dom-input-value) |
| Blob 预览 URL | createObjectURL 生成指向 Blob／File 的地址；File API 规定创建文档卸载时清理对应 URL store 条目。保存该字符串不能可靠跨刷新复原图片。[MDN createObjectURL](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static)、[W3C 生命周期](https://w3c.github.io/FileAPI/#lifeTime) |
| 可另做的本地持久化 | Blob／File 支持结构化序列化，不能声称浏览器绝对无法持久保存图片；但普通 sessionStorage 字符串保存不自动提供这一能力。[W3C Blob／File](https://w3c.github.io/FileAPI/#blob-section)、[WHATWG Storage](https://html.spec.whatwg.org/multipage/webstorage.html#the-storage-interface) |
| 服务端已上传素材引用 | 平台素材 ID／状态是后端资源引用，区别于本地 File 和 blob URL；是否仍可用、是否属本人及能否发送须回查平台，不能仅凭本地缓存判断。依据：[既定素材设计](../../数据库设计/会话运行与消息/通用素材与工具操作设计.md)。 |

W3C File API 来源为编辑草案；本次只引用已有 File／Blob 表达、序列化及 URL 生命周期规则，没有验证浏览器的特殊表单恢复行为。

## 5. 支持下一轮的产品取舍

建议一期承诺：**普通文字在同标签页、同登录用户、同业务 Session 下尽力跨刷新恢复；未发送的本地图片刷新后重新选择。**不能把此承诺扩展为关浏览器后、跨标签或跨设备可靠恢复。

建议不在普通文字草稿中保存原图、base64 或 blob URL，不为刷新恢复额外引入本地文件持久库。图片预览能显示仅代表本地读取成功，不代表上传完成或消息已接纳。

“重新选择”针对尚未形成可核验服务器引用的本地选择；已有正式消息中的图片仍从后端事实恢复。已经上传但尚未发送的素材引用可有独立恢复策略，不能被本地重选规则顺带删除；该策略及上传结果未知时的处理仍需产品／接口明确。

## 6. 后续最小验证点

| 类别 | 待证明的行为 |
| --- | --- |
| 文字恢复 | Chrome／Edge 同标签刷新恢复最近成功保存文字；切业务 Session 不串草稿，恢复不自动发送。 |
| 登录边界 | 退出、401、身份切换及无权 Session 均不展示旧草稿；其他标签自行获知失效后也清理。 |
| 标签边界 | 手动新标签、带 opener／noopener 打开及浏览器复制标签；确认副本不会被误认为共享状态。 |
| 异常降级 | 存储禁止、写入失败、损坏记录、用户清理站点数据时，输入仍可编辑且提示准确。 |
| 图片状态 | 本地选取、预览、上传中、上传结果未知、上传成功未发送及消息已接纳分别刷新，状态不混淆。 |
| 资源管理 | 删除／替换预览时释放旧对象 URL；服务端素材仍执行归属及状态校验，不能由路径字符串恢复本地文件。 |

以上均为待实施场景；研究支持该取舍的技术可行性和边界，不证明草稿恢复、上传或真实 Web 流程已经通过。
