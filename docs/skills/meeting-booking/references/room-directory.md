# 会议室名录与同名冲突

本文件供 `meeting-booking` Skill 消歧与展示使用。预约时必须以 `room.search` 返回的 `chamberId` 作为 `roomId`；下表不能代替实时可用性查询。

## 同名冲突清单

| 词汇 | 会议室指向 | 系统指向 |
| --- | --- | --- |
| 萤火虫 | 萤火虫会议室（16F，约 10 人） | 萤火虫安全保障平台 |
| 郁金香 | 郁金香会议室（17F，约 20 人） | 郁金香商务管理平台 |
| 向日葵 | 向日葵会议室（17F，约 8 人） | 向日葵项目管理系统 |
| 满天星 | 满天星会议室（17F，约 4 人） | 满天星数字办公系统 |
| 蒲公英 | 蒲公英会议室（18F，约 10 人） | 蒲公英数智运营服务平台 |

## 楼层约束

`room.search` 的 `floor` 仅接受：`16`、`17`、`18`（按会议室编号前两位筛选）。

## 使用注意

- 用户只说系统产品名且上下文是登录/审批/故障时，不要按会议室预订处理。
- 用户说“订满天星/向日葵”且语境为开会时，按会议室处理，并用 `room.search` 匹配实时 `chamberId`。
- 名录中的人数为参考容量；实际以 `room.search` 的 `maxPeople` 及预约时服务端校验为准。
- 勿编造未在 search 结果中出现的会议室。
