## 3. 消歧判定顺序

1. **会议室信号词**：开会、会议室、预订、订、楼层、16F/17F/18F、容纳 N 人、投屏、白板、场地、约人 → 判定会议室。
2. **系统信号词**：系统、平台、登录、OA、流程、审批、故障、账号、密码、项目管理、运营、安全、工单、报账单 → 判定系统，本 Skill 不介入。
3. **两类信号同时出现** → 以动词为准：「订 / 预约 / 开会」指向会议室；「打开 / 登录 / 查 / 审批」指向系统。仍不决就问。
4. **两类信号都无** → 必须提问，示例：「您是指预订 17F 的郁金香会议室（20 人），还是登录郁金香商务管理平台？」
