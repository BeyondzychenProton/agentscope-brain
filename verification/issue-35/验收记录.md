## 实现

- `InitialPasswordService` 在有效受限身份下验证当前密码；新密码至少 12 个 Unicode 码点、有效 UTF-8 不超过 72 字节，登录与改密共用字节预检。编码沿用 `{bcrypt}`、cost 12，拒绝未知／noop 标识。
- 慢哈希在短写事务外完成。事务依次锁定平台用户、相关身份行，复核版本和原始凭据；原子更新凭据版本／首次改密标记／改密时间、安全版本／真实操作者来源，并追加 `INITIAL_PASSWORD_CHANGE` 成功审计。可信用户来自服务端 principal，客户端 owner／UserId／版本字段不生效。
- SQL 完成后轮换 Session ID／CSRF，保存新安全版本 principal；`authenticatedAt`、`absoluteExpiresAt` 直接沿用本次原登录值，绝不重新计算 24 小时。旧安全版本在服务端复核时拒绝。
- SQL 提交异常只在新事务中做一次带锁独立核对：本次编码哈希、凭据／安全版本、首次改密状态及本请求 UUID 审计全部匹配才证明提交。不重跑改密；不能证明为 `503 AUTH_OUTCOME_UNCERTAIN`。
- 已证明 SQL 成功但换发／保存会话失败为 `503 PASSWORD_CHANGED_RELOGIN_REQUIRED`，清理当前上下文并过期 Cookie，不回滚密码或恢复旧版本。改密响应在外层缓冲，等待 Session JDBC 请求末尾保存结束后才发出，最终保存失败可替换尚未发送的 200。
- Vue 页面提供当前／新／确认密码；提交期间防重复，写请求不自动重试，提交结束和离页清除口令。部分成功明确使用新密码重新登录；结果不明停止提交，提示先验证登录，不解释成“密码未改”。基础工作台仅展示当前身份和退出，不运行业务。
