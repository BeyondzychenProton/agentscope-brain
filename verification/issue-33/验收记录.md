## 实现与证明边界

没有物理外键、触发器或存储过程。单表 CHECK／唯一键负责结构；跨行引用、固定锚点和生命周期由只读巡检及受控条件 SQL 证明。不宣称具有任意 UPDATE 权限的操作者无法同时修改正文、摘要、历史及全部引用。阶段 2 的业务实现必须使用同样的写入条件、锁序和提交预算。

`business_session.projection_stream_id` 的 NULL／0 和 `run_progress` 全空投影扩展组仅保留既有 SQL 夹具尚未建立投影的情况。新应用首次接纳必须同事务建立流及首批；本探针不声称未接入投影的旧夹具已经满足运行契约。合成 cursor 仅展示字段和预算可承载，不实现或证明服务端真实游标签发、权限、读取水位或分页。

INLINE 保存精确正文；FIXED_REF 只允许正式 TEXT 块或不可变交互修订，必须按指定定位、版本、字节数和摘要读回。可变工具行只作事实来源，展示历史保存独立有界快照；后续修改工具归一化结果不改写旧回执。素材引用没有证明 MinIO 原件可读取。

禁止字段名的 SQL 扫描属于防御性巡检，独立递归 JSON 检查只覆盖合成样本；它们不能识别任意文字里的秘密，也不能替代应用 Adapter 递归白名单、参数脱敏和原始 Thinking 隔离。确认恢复副本只存在于 09 的原占位夹具，投影没有拷贝它们。所有调用／保存／读回字段仍是合成证据，不等于真实 SDK 持久化或应用收尾证明。
