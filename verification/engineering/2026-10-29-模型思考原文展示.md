# 模型思考原文展示

用户于 2026-10-29 要求简单展示大模型思考原文：固定高度框，正文 SSE 开始后自动折叠。这里的 SSE 开始按“回答正文消息开始”实现；reasoning 本身也通过 SSE 传输。

实现沿用正式 React / CopilotKit / AgentScope AG-UI 链路：开启官方 adapter 的 reasoning 事件，在 CopilotKit 的 reasoningMessage 插槽显示纯文本。高度 180px，自动滚动到底部；正文开始自动折叠一次，支持键盘操作和手动展开，后续正文不会反复折叠。使用 pre 和 React 文本转义，保留换行及 Markdown 标记原文，不解释 HTML。

RunDisplay 在既有 display_json 中保存独立 role=reasoning 消息，刷新后可展开；正文历史 content 不含思考文字，不作为下一轮模型输入。没有返回 reasoning 的模型不显示空框，也不生成演示思考内容。合并了 reasoning_content 与 content 的模型 chunk 会先转发思考、后转发正文。沿用既有输出大小限制，不新增 DDL。

实际验证基于本地 `7bbc86e` 及工作区修改：

- Maven verify：114 项测试通过，另有 1 项正式制品检查通过。包含真实 SDK / transport 对 reasoning 分段和同 chunk 正文的验证、思考原文读回、正文分离，以及既有工具执行回归。
- React 类型检查、Next.js 生产构建通过。
- 已登录 Chrome 浏览器 → Runtime → Java → 合成模型 → AG-UI → 页面整条链路通过。观察正文前原文可见、180px 高度、内容溢出可滚动、正文前后展开状态变化、手动展开、完成后刷新恢复；模型调用始终为 1 次，无页面 JavaScript 错误。
- 验证使用独占回环 MySQL 和合成身份/模型，不修改共享数据库，没有部署真实用户入口。真实模型是否返回 reasoning 取决于该模型能力与配置，本次没有用真实模型验收。
