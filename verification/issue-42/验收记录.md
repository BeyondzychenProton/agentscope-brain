## 交付与边界

- `GET /api/sessions`：可信当前用户、员工范围、本人未归档列表、服务端标题子串搜索、最近活动倒序和 ID 倒序分页。默认 50／上限 100，200 Unicode 码点查询上限；转义 LIKE 通配字符，不搜索消息正文。
- 游标绑定用途、本人、员工、规范化查询及时间／ID 继续位置；每页复核身份。`updatedAt` 对应 UTC `last_activity_at`，明确按 UTC 读写定位，保留微秒和无符号 BIGINT 字符串精度。稳定密钥允许进程重启续页，随机密钥重启后要求重新搜索。跨页不是冻结列表快照；新业务活动后的完整顺序通过重新搜索刷新。
- 侧栏显示真实列表、加载更多、搜索／空态／重试；点选高亮并读取现有 TEXT 历史，支持深链刷新。切换／搜索／退出后的迟到响应不能重新填入旧列表；历史分页亦核对当前加载代次。标题与正文按字面展示。
- 本人历史在撤权后可读；账号失效或受限改密拒绝列表。已有结构与投影可用性边界继续生效。新建对话仍仅清除本地 Session 定位，不创建空业务 Session。
- 本次 `allowedActions` 为空；活动 Run 仅返回已持久 ID／业务状态，`processingStatus` 为 null。真实调度解释、改名、composer／提交接纳、模型执行、完整投影／SSE、Markdown 及过程时间线均未交付。此切片完成不等于 #42 全部完成或阶段 2 通过。
