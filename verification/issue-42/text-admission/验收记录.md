本地开发和隔离集成已完成：本机浏览器输入文字，经正式 HTTP 接纳，在同一个平台事务内创建必要 Session、正式 USER 消息、Run、WAITING dispatch、不可变文字投影和接纳审计；回查及刷新恢复同一事实。图片、FORM、改名、实际 Agent／模型执行、正式员工回复、完整投影 events／SSE 与过程时间线留在后续切片。

`brain.conversation.text-submission-enabled` 默认 **false**，共享 YAML 与共享数据库未修改。隔离执行器显式开启；缺容量控制、缺已有 READY 记忆控制或计数不一致时拒绝接纳，不自动建表、造控制事实或初始化记忆原件。此开关不是用户授权，接纳仍在锁内复核可信身份、固定发布和当前授权。当前环境没有交付执行器，页面明确显示接纳后等待事实，不展示模拟回复。

## 关键行为

- 新建按钮仍不创建空 Session；发送准备才以 actor＋clientIntentId 登记意图，冻结发布及图片策略摘要。首次接纳重新核对默认发布，原意图至多绑定一个 Session；另一个提交键命中已绑定意图返回原结果定位。
- 普通消息保留完整原文及服务端规范摘要。同键同语义返回原结果，同键异参拒绝；已经接纳的结果不被满队、撤权或功能关闭覆盖。公开 BIGINT 字段必须是字符串，不接受数字 ID／正文的隐式转换；上传集合本切片只能为空。
- 预登记先独立提交；正式接纳 C0→L1→员工／发布／授权→意图／提交→memory_profile→Session→消息／Run→dispatch→展示／审计。SQL 接纳失败整体回滚，控制记录保留原键供回查。无网络／用户等待跨越业务锁。
- 原键 close 在身份／控制锁内与接纳互斥。没有登记时落无目标／无语义的永久墓碑；已有登记不抹掉原语义。先接纳则返回原结果；先封闭则迟到旧键永久拒绝。GET 查无记录是 UNOBSERVED，不创建墓碑、不解冻输入。
- 前端发送前固定原键和原文。结果不明时冻结，刷新只 GET 回查；明确封闭后才能编辑、新键发送。新建意图重新准备只发生在已确认封闭之后，不偷偷替换旧准备。确认接纳才清理对应草稿。
- 普通文字按当前可信用户、员工、业务 Session／本地新建意图保存在标签页 sessionStorage。配额失败保留页内文字并提示恢复边界。退出、失效、已知身份切换清理应用前缀；已离页请求不能把旧草稿写回。
- Enter 发送、Shift+Enter 换行，composition 及候选确认按键不发送。窗口聚焦身份复核期间保留已确认视图和草稿编辑，只暂停发送；身份变化／失效后清理对应视图。
- 投影使用既有 web-projection-v1 四项变更：SESSION_SET、RUN_SET、CONTENT_SET、MESSAGE_COMMIT。纯文字正文、版本、UTF-8 长度／SHA-256 和批次同事务保存。TEXT 快照仅扩展到有匹配接纳／WAITING 账本且无 SDK 调用的 ACCEPTED Run；未知执行状态仍受控拒绝，不伪装完整恢复。
